Tarea 2: Listado Parametrizado por Argumentos

Explicación del Ejercicio

En esta segunda tarea se amplía la funcionalidad del listado de directorios mediante el paso de argumentos por línea de comandos (args)[cite: 11]. Esto permite consultar dinámicamente cualquier ruta especificada al ejecutar el programa[cite: 11].

Conceptos y métodos clave:

  • Control de parámetros de entrada: Se valida si el array args contiene elementos (args.length == 0) para prevenir excepciones en tiempo de ejecución al intentar acceder a rutas no definidas[cite: 11].
  • Comprobación de existencia (exists()): Antes de procesar el contenido, se verifica mediante directorio.exists() si la ruta introducida existe en el sistema de archivos[cite: 11].
  • Gestión de contenido: Si la ruta es válida y existe, se obtiene el array mediante listFiles() y se muestra el listado por consola; en caso contrario, se notifica el error correspondiente[cite: 11].

Código Fuente y Salida

Clase1.java 
package ClaseFile;

import java.io.File;

/**
 * @author Eva Gallardo Romero
 * @date 17 de sep de 2026
 * Muestra todo el contenido de un directorio determinado
 */

public class Clase1 {
	
    public static void main(String[] args) {
		
        // compruebo que se ha introducido una ruta 
        if (args.length == 0) {
            System.out.println("Error: Debes proporcionar la ruta del directorio como argumento.");
            return;
        }
		
        // objeto File que representa el directorio actual
        File directorio = new File(args[0]);
		
        // obtengo la lista de elementos que hay en el directorio
        File[] contenido = directorio.listFiles();
        
        // recorro el contenido que he obtenido del directorio y lo printeo
        if (directorio.exists()) {
            // recorro el contenido que he obtenido del directorio y lo printeo
            if (contenido != null) {
                System.out.println("Este es el contenido existente en Ficheros");
                for (int i = 0; i < contenido.length; i++) {
                    System.out.println(contenido[i]);
                }
            } else {
                System.out.println("No hay contenido en el directorio");
            }
        } else {
            System.out.println("El directorio introducido no existe");
        }

    }

}
