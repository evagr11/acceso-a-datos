Tarea 1: Listado del Directorio Actual

Explicación del Ejercicio

En esta primera tarea se hace uso de la clase java.io.File para acceder al sistema de archivos local y consultar la estructura de carpetas y archivos del proyecto[cite: 10].

Conceptos y métodos clave:

  • Instanciación con ruta relativa: Se crea una instancia de File pasando como parámetro el punto ("."), lo que representa el directorio actual donde se está ejecutando el programa[cite: 10].
  • Obtención de ficheros (listFiles()): Se invoca el método listFiles() para obtener un array de objetos File[] que contiene cada elemento dentro del directorio[cite: 10].
  • Validación y recorrido: Se comprueba que la lista devuelta no sea nula (contenido != null) para evitar excepciones de puntero nulo (NullPointerException) y se itera mediante un bucle for imprimiendo cada elemento[cite: 10].

Código Fuente y Salida

Clase0.java 
package ClaseFile;

import java.io.File;

/**
 * @author Eva Gallardo Romero
 * @date 16 de sep de 2026
 * Muestra todo el contenido del directorio actual
 */
public class Clase0 {

    public static void main(String[] args) {
        
        // objeto File que representa el directorio actual
        File directorio = new File(".");
        
        // obtengo la lista de elementos que hay en el directorio
        File[] contenido = directorio.listFiles();
        
        // recorro el contenido que he obtenido del directorio y lo printeo
        if (contenido != null) {
            System.out.println("Este es el contenido existente en Ficheros");
            for (int i = 0; i < contenido.length; i++) {
                System.out.println(contenido[i]);
            }
        } else {
            System.out.println("No hay contenido en el directorio");
        }

    }

}
