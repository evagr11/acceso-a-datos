Página 2: Formas de declarar un fichero

No es un programa completo, sino varios ejemplos sueltos que muestran las distintas formas de crear un objeto File: con la ruta completa en un único String, o separando el directorio del nombre de fichero.

Ejemplos · declaración de File 
//Windows
File fichero1 = new File( "C:\\EJERCICIOS\\UNI1\\ejemplo1.txt");
//Linux
File fichero1 = new File( "/home/ejercicios/uni1/ejemplo1.txt");

String directorio= "C:/EJERCICIOS/UNI1";
File fichero2 = new File(directorio, "ejemplo2.txt");

File direc = new File(directorio);

Explicación línea a línea

  1. 1
    File fichero1 = new File("C:\\EJERCICIOS\\UNI1\\ejemplo1.txt");

    Primer constructor: la ruta completa (directorio + fichero) en un único String. En Windows el separador es \, y hay que escribirlo doble (\\) porque la barra invertida es un carácter especial en Java.

  2. 2
    File fichero1 = new File("/home/ejercicios/uni1/ejemplo1.txt");

    La misma idea, pero en Linux, donde el separador de rutas es / y no hace falta escaparlo.

  3. 3
    String directorio= "C:/EJERCICIOS/UNI1";

    Se guarda solo la ruta del directorio en una variable de texto aparte, para reutilizarla.

  4. 4
    File fichero2 = new File(directorio, "ejemplo2.txt");

    Segundo constructor: se pasan dos String por separado, el directorio y el nombre del fichero; File se encarga de unirlos correctamente.

  5. 5
    File direc = new File(directorio);

    Un objeto File no tiene por qué apuntar a un fichero: aquí apunta a un directorio, usando ese mismo File como base para el siguiente ejemplo (Página 3).

En resumen: File tiene varios constructores para representar la misma ruta de distintas formas (todo junto, o directorio y nombre por separado), y puede representar tanto ficheros como directorios.

Página 3: VerDir

Antes del programa, la Página 3 muestra un tercer constructor de File: File fichero3 = new File(direc, "ejemplo3.txt"); (un File de directorio + un nombre de fichero). Después, el programa VerDir lista los ficheros del directorio actual y, para cada uno, comprueba si es un fichero o un directorio.

VerDir.java 
import java.io.*;

public class VerDir {

    public static void main(String[] args) {
        String dir = ".";
        File f = new File(dir);
        String[] archivos = f.list();
        System.out.printf("Ficheros en el directorio actual: %d %n",
                            archivos.length);
        for (int i = 0; i < archivos.length; i++) {
            File f2 = new File(f, archivos[i]);
            System.out.printf("Nombre: %s, es fichero?: %b, es directorio?: %b %n", archivos[i], f2.isFile(),f2.isDirectory());
        }
    }
}

Explicación línea a línea

  1. 1
    String dir = ".";

    El punto "." es un atajo que representa el directorio actual (desde donde se ejecuta el programa).

  2. 2
    File f = new File(dir);

    Se crea un File que apunta a ese directorio actual.

  3. 3
    String[] archivos = f.list();

    list() devuelve un array de String con los nombres de todo lo que hay dentro de ese directorio (ficheros y subdirectorios).

  4. 4
    System.out.printf("Ficheros en el directorio actual: %d %n", archivos.length);

    Se imprime cuántos elementos se han encontrado, usando printf con %d (número entero) y %n (salto de línea).

  5. 5
    for (int i = 0; i < archivos.length; i++) {

    Se recorre cada nombre devuelto por list().

  6. 6
    File f2 = new File(f, archivos[i]);

    Se crea un nuevo File combinando el directorio f con cada nombre, para poder consultar sus propiedades individualmente (mismo constructor visto en la Página 3, directorio + nombre).

  7. 7
    System.out.printf("Nombre: %s, es fichero?: %b, es directorio?: %b %n", ...);

    Se imprime el nombre junto con el resultado de isFile() e isDirectory(), usando %s para texto y %b para booleanos.

En resumen: el programa usa list() para obtener los nombres del directorio actual y, por cada uno, crea un File aparte para poder preguntarle si es un fichero o un directorio.

Página 4: VerInf

Antes del programa, la Página 4 muestra dos variantes rápidas del ejemplo VerDir: apuntar a otro directorio fijo (File f = new File("d:\\db");) o a uno indicado por el usuario al ejecutar el programa (String dir=args[0];). Después, el programa VerInf muestra información detallada de un fichero concreto usando varios métodos de File.

VerInf.java 
import java.io.*;

public class VerInf {

    public static void main(String[] args) {
        System.out.println("INFORMACIÓN SOBRE EL FICHERO:");
        File f = new File("D:\\ADAT\\UNI1\\VerInf.java");
        if(f.exists()){
            System.out.println("Nombre del fichero : "+f.getName());
            System.out.println("Ruta                : "+f.getPath());
            System.out.println("Ruta absoluta       : "+f.getAbsolutePath());
            System.out.println("Se puede leer       : "+f.canRead());
            System.out.println("Se puede escribir   : "+f.canWrite());
            System.out.println("Tamaño              : "+f.length());
            System.out.println("Es un directorio    : "+f.isDirectory());
            System.out.println("Es un fichero       : "+f.isFile());
            System.out.println("Nombre del directorio padre: "+f.getParent());
        }
    }
}

Explicación línea a línea

  1. 1
    System.out.println("INFORMACIÓN SOBRE EL FICHERO:");

    Se imprime una cabecera para el listado que viene a continuación.

  2. 2
    File f = new File("D:\\ADAT\\UNI1\\VerInf.java");

    Se apunta a un fichero concreto mediante su ruta absoluta completa en Windows.

  3. 3
    if(f.exists()){

    Antes de preguntar por sus propiedades, se comprueba que el fichero realmente existe; si no, no tendría sentido pedirle información.

  4. 4
    f.getName()

    Devuelve solo el nombre del fichero, sin la ruta: VerInf.java.

  5. 5
    f.getPath()

    Devuelve la ruta tal y como se usó para construir el File.

  6. 6
    f.getAbsolutePath()

    Devuelve la ruta absoluta completa en el sistema de ficheros.

  7. 7
    f.canRead() / f.canWrite()

    Indican si el fichero se puede leer y si se puede escribir, respectivamente (permisos).

  8. 8
    f.length()

    Devuelve el tamaño del fichero, en bytes.

  9. 9
    f.isDirectory() / f.isFile()

    Indican si lo que representa el objeto File es un directorio o un fichero normal.

  10. 10
    f.getParent()

    Devuelve el nombre del directorio que contiene a este fichero (su "padre").

Página 5: CrearDir

El programa CrearDir crea un directorio nuevo, crea dos ficheros vacíos dentro de él, renombra uno de esos ficheros y crea un tercer fichero usando una ruta de texto directamente. Después se muestra cómo borrar un fichero con delete().

CrearDir.java 
import java.io.*;

public class CrearDir {

    public static void main(String[] args) {
        File d = new File("NUEVODIR");
        File f1 = new File(d,"FICHERO1.TXT");
        File f2 = new File(d,"FICHERO2.TXT");

        d.mkdir();

        try {
            if (f1.createNewFile())
                System.out.println("FICHERO1 creado correctamente...");
            else
                System.out.println("No se ha podido crear FICHERO1...");

            if (f2.createNewFile())
                System.out.println("FICHERO2 creado correctamente...");
            else
                System.out.println("No se ha podido crear FICHERO2...");
        } catch (IOException ioe) {ioe.printStackTrace();}

        f1.renameTo(new File(d,"FICHERO1NUEVO"));

        try {
            File f3 = new File("NUEVODIR/FICHERO3.TXT");
            f3.createNewFile();
        } catch (IOException ioe) {ioe.printStackTrace();}
    }
}

Explicación línea a línea

  1. 1
    File d = new File("NUEVODIR");

    Se declara un File que representará el directorio que se va a crear.

  2. 2
    File f1 = new File(d,"FICHERO1.TXT"); / File f2 = new File(d,"FICHERO2.TXT");

    Se declaran dos ficheros dentro de ese directorio, usando el constructor File(File, String).

  3. 3
    d.mkdir();

    Se crea físicamente el directorio NUEVODIR en disco. Hasta este punto, d solo era un objeto en memoria.

  4. 4
    if (f1.createNewFile()) ... else ...

    createNewFile() crea el fichero vacío y devuelve true si lo ha creado, o false si ya existía; se avisa por pantalla del resultado. Se repite lo mismo para f2.

  5. 5
    } catch (IOException ioe) {ioe.printStackTrace();}

    createNewFile() puede lanzar IOException, por eso va dentro de un try-catch; si algo falla, se imprime la traza del error.

  6. 6
    f1.renameTo(new File(d,"FICHERO1NUEVO"));

    Se renombra FICHERO1.TXT a FICHERO1NUEVO, indicando el nuevo nombre como otro objeto File.

  7. 7
    File f3 = new File("NUEVODIR/FICHERO3.TXT");

    Esta vez se apunta al nuevo fichero con una única ruta de texto (en vez de File+String), mezclando / como separador dentro de NUEVODIR.

  8. 8
    f3.createNewFile();

    Se crea el tercer fichero, vacío, dentro de NUEVODIR.

A continuación, el libro muestra cómo borrar el fichero f2 con delete() (no se puede borrar NUEVODIR directamente mientras contenga ficheros):

borrar fichero 
if(f2.delete())
    System.out.println("Fichero borrado...");
else
    System.out.println("No se ha podido borrar el fichero...");
En resumen: mkdir() crea directorios, createNewFile() crea ficheros vacíos, renameTo() renombra y delete() borra; para borrar un directorio primero hay que borrar (o mover) todo lo que contiene.

Página 12: LeerFichTexto

El programa LeerFichTexto lee, carácter a carácter, el propio fichero fuente LeerFichTexto.java usando FileReader (flujo de caracteres, en vez de bytes) y muestra cada carácter por pantalla.

LeerFichTexto.java 
import java.io.*;

public class LeerFichTexto {

    public static void main(String[] args) throws IOException {
        //declarar fichero
        File fichero =
            new File("C:\\EJERCICIOS\\UNI1\\LeerFichTexto.java");
        //crear el flujo de entrada hacia el fichero
        FileReader fic = new FileReader(fichero);
        int i;
        while ((i = fic.read()) != -1)
            System.out.println((char) i);
        fic.close();
    }
}

Explicación línea a línea

  1. 1
    public static void main(String[] args) throws IOException {

    Como este programa no usa try-catch, delega el manejo de la excepción hacia fuera con throws IOException.

  2. 2
    File fichero = new File("C:\\EJERCICIOS\\UNI1\\LeerFichTexto.java");

    Se apunta al propio fichero fuente del programa (ruta absoluta en Windows).

  3. 3
    FileReader fic = new FileReader(fichero);

    Se crea el flujo de entrada de caracteres hacia el fichero (a diferencia de FileInputStream, que trabaja con bytes).

  4. 4
    int i;

    Variable donde se guardará cada carácter leído (como número entero).

  5. 5
    while ((i = fic.read()) != -1)

    read() lee un carácter y lo devuelve como int; el bucle continúa mientras el valor devuelto sea distinto de -1 (fin de fichero).

  6. 6
    System.out.println((char) i);

    Se convierte i a char mediante un cast ((char) i) para mostrarlo como el carácter que realmente es, no como su valor numérico.

  7. 7
    fic.close();

    Se cierra el flujo de lectura.

El libro añade que, para leer de golpe bloques de 20 caracteres en vez de uno a uno, se puede usar la variante de read() que recibe un array:

lectura por bloques 
char b[]= new char[20];
while ((i = fic.read(b)) != -1) System.out.println(b);

read(b) rellena el array b con hasta 20 caracteres de una vez y devuelve cuántos ha leído realmente (o -1 al llegar al final); es más eficiente que leer carácter a carácter.

En resumen: FileReader permite leer un fichero de texto carácter a carácter (o por bloques), haciendo cast a char para interpretarlo como texto y no como números.

Página 13: EscribirFichTexto

El programa EscribirFichTexto escribe, carácter a carácter, el contenido de un String en un fichero de texto usando FileWriter, y añade un * al final con append().

EscribirFichTexto.java 
import java.io.*;

public class EscribirFichTexto {

    public static void main(String[] args) throws IOException {
        File fichero = new
            File("C:\\EJERCICIOS\\UNI1\\FichTexto.txt");
        FileWriter fic = new FileWriter(fichero);

        String cadena ="Esto es una prueba con FileWriter";
        char[] cad = cadena.toCharArray();
        for(int i=0; i<cad.length; i++)
            fic.write(cad[i]);

        fic.append('*');
        fic.close();
    }
}

Explicación línea a línea

  1. 1
    File fichero = new File("C:\\EJERCICIOS\\UNI1\\FichTexto.txt");

    Se apunta al fichero de texto que se va a crear/sobrescribir.

  2. 2
    FileWriter fic = new FileWriter(fichero);

    Se crea el flujo de salida de caracteres; si el fichero ya existía, su contenido anterior se borra (por defecto no se añade al final).

  3. 3
    String cadena ="Esto es una prueba con FileWriter";

    Se declara el texto que se quiere escribir en el fichero.

  4. 4
    char[] cad = cadena.toCharArray();

    Se convierte el String en un array de char, para poder recorrerlo y escribirlo carácter a carácter.

  5. 5
    for(int i=0; i<cad.length; i++) fic.write(cad[i]);

    Se recorre el array y se escribe cada carácter, uno a uno, con write(int).

  6. 6
    fic.append('*');

    append() añade un carácter (o texto) al final de lo ya escrito, sin sobrescribir nada.

  7. 7
    fic.close();

    Se cierra el flujo, asegurando que todo lo escrito queda guardado en el fichero.

El libro añade que, en vez de escribir carácter a carácter, se puede escribir un array entero de golpe con fic.write(cad), y muestra un ejemplo escribiendo varias cadenas seguidas desde un array de String (continúa en la Página 14):

escritura de un array de Strings 
String prov[] =
    {"Albacete","Avila","Badajoz","Cáceres","Huelva","Jaén",
     "Madrid","Segovia","Soria","Toledo","Valladolid","Zamora"};

for(int i=0; i<prov.length; i++) fic.write(prov[i]);

Aquí write(String) escribe cada provincia completa de una vez; como no se añade ningún salto de línea entre una y otra, quedarán todas pegadas seguidas en el fichero.

En resumen: FileWriter permite escribir texto carácter a carácter, un array de caracteres de golpe, o directamente un String completo con write(String); append() añade contenido sin borrar lo anterior.

Página 14: LeerFichTextoBuf

Antes del programa, el libro muestra que FileWriter fic = new FileWriter(fichero, true); permite añadir al final de un fichero en vez de borrar su contenido (segundo parámetro true), y que BufferedReader se construye envolviendo un FileReader. El programa LeerFichTextoBuf usa esa combinación para leer un fichero línea a línea (en vez de carácter a carácter).

LeerFichTextoBuf.java 
import java.io.*;

public class LeerFichTextoBuf {

    public static void main(String[] args) {
        try{
            BufferedReader fichero = new BufferedReader(
                            new FileReader("LeerFichTexto.java"));
            String linea;
            while((linea = fichero.readLine()) !=null)
                System.out.println(linea);

            fichero.close();
        }
        catch (FileNotFoundException fn ){
            System.out.println("No se encuentra el fichero");}
        catch (IOException io) {
            System.out.println("Error de E/S ");}
    }
}

Explicación línea a línea

  1. 1
    try{

    Aquí todo el trabajo con ficheros se agrupa dentro de un try-catch, en vez de usar throws IOException en main.

  2. 2
    BufferedReader fichero = new BufferedReader(new FileReader("LeerFichTexto.java"));

    Se envuelve un FileReader con un BufferedReader, que añade un búfer de lectura eficiente y, sobre todo, el método readLine() (leer líneas completas), algo que FileReader no tiene por sí solo.

  3. 3
    String linea;

    Variable donde se guardará cada línea leída.

  4. 4
    while((linea = fichero.readLine()) !=null)

    readLine() lee una línea completa y la devuelve, o devuelve null al llegar al final del fichero; el bucle continúa mientras haya líneas.

  5. 5
    System.out.println(linea);

    Se imprime la línea leída tal cual, sin necesidad de cast (ya es un String, no un número como con read()).

  6. 6
    fichero.close();

    Se cierra el flujo dentro del propio bloque try, tras terminar de leer.

  7. 7
    catch (FileNotFoundException fn ){ ... } catch (IOException io) { ... }

    Se capturan por separado dos posibles errores: que el fichero no exista (FileNotFoundException), o cualquier otro error de entrada/salida (IOException), mostrando un mensaje distinto para cada caso.

En resumen: BufferedReader envuelve a FileReader para poder leer el fichero línea a línea con readLine(), en vez de carácter a carácter; el fin de fichero se detecta aquí con null, no con -1.

Páginas 14-15: EscribirFichTextoBuf

Antes del programa, el libro muestra que BufferedWriter se construye envolviendo un FileWriter, igual que pasaba con BufferedReader. El programa EscribirFichTextoBuf escribe 10 líneas de texto en un fichero, saltando de línea después de cada una con newLine().

EscribirFichTextoBuf.java 
import java.io.*;

public class EscribirFichTextoBuf {

    public static void main(String[] args) {
        try{
            BufferedWriter fichero = new BufferedWriter
                        (new FileWriter("FichTexto.txt"));

            for (int i=1; i<11; i++){
                fichero.write("Fila numero: "+i);
                fichero.newLine();
            }
            fichero.close();
        }
        catch (FileNotFoundException fn ){
                System.out.println("No se encuentra el fichero");}
        catch (IOException io) {
                System.out.println("Error de E/S ");}
    }
}

Explicación línea a línea

  1. 1
    BufferedWriter fichero = new BufferedWriter(new FileWriter("FichTexto.txt"));

    Se envuelve un FileWriter con un BufferedWriter, que añade un búfer para escribir caracteres de forma eficiente y aporta el método newLine().

  2. 2
    for (int i=1; i<11; i++){

    Bucle que recorre los números del 1 al 10 (10 vueltas en total).

  3. 3
    fichero.write("Fila numero: "+i);

    Se escribe el texto "Fila numero: " concatenado con el número de la vuelta actual.

  4. 4
    fichero.newLine();

    Se escribe un salto de línea, para que la siguiente fila quede en una línea nueva.

  5. 5
    fichero.close();

    Se cierra el flujo una vez escritas las 10 líneas.

En resumen: BufferedWriter añade a FileWriter un búfer eficiente y el método newLine() para no tener que escribir el salto de línea a mano.

Página 15: Reescritura con PrintWriter

El libro presenta PrintWriter (también deriva de Writer) como alternativa más cómoda: tiene los métodos print() y println(), igual que System.out, y println() añade el salto de línea automáticamente. Se construye envolviendo un FileWriter. Con esto, el ejemplo de EscribirFichTextoBuf se puede reescribir así, mucho más corto:

reescritura con PrintWriter 
PrintWriter fichero = new PrintWriter
                (new FileWriter("FichTexto.txt"));
for(int i=1; i<11; i++)
        fichero.println("Fila numero: "+i);
fichero.close();

Explicación línea a línea

  1. 1
    PrintWriter fichero = new PrintWriter(new FileWriter("FichTexto.txt"));

    Se envuelve un FileWriter con un PrintWriter, que aporta los métodos print() y println().

  2. 2
    for(int i=1; i<11; i++)

    Mismo bucle de antes: del 1 al 10.

  3. 3
    fichero.println("Fila numero: "+i);

    Se escribe la línea y se salta de línea en la misma instrucción; ya no hace falta llamar a newLine() por separado como con BufferedWriter.

  4. 4
    fichero.close();

    Se cierra el flujo, igual que en los ejemplos anteriores.

En resumen: PrintWriter hace lo mismo que BufferedWriter + newLine(), pero en menos código, reutilizando los métodos print()/println() que ya se conocen de System.out.

Página 16: EscribirFichBytes

Este programa escribe los números del 1 al 99 en un fichero byte a byte usando FileOutputStream, y a continuación vuelve a leer ese mismo fichero con FileInputStream, mostrando cada valor leído por consola.

EscribirFichBytes.java 
import java.io.*;

public class EscribirFichBytes {

    public static void main(String[] args) throws IOException {

        File fichero = new File("c:\\...");

        FileOutputStream fileout = new FileOutputStream(fichero);

        FileInputStream filein = new FileInputStream(fichero);

        int i;

        for (i = 1; i < 100; i++) {
            fileout.write(i);
        }

        fileout.close();

        while ((i = filein.read()) != -1) {
            System.out.println(i);
        }

        filein.close();
    }
}

Explicación línea a línea

  1. 1
    import java.io.*;

    Se importan todos los paquetes de java.io, donde están las clases para trabajar con ficheros y flujos de entrada/salida (File, FileOutputStream, FileInputStream...).

  2. 2
    public class EscribirFichBytes {

    Se declara una clase pública llamada EscribirFichBytes.

  3. 3
    public static void main(String[] args) throws IOException {

    Se declara el método main: es estático, no devuelve nada (void) y recibe como argumento un array de String llamado args. Además, puede lanzar una excepción de tipo IOException.

  4. 4
    File fichero = new File("c:\...");

    Se crea una variable fichero de tipo File, indicando como argumento la ruta del archivo.

  5. 5
    FileOutputStream fileout = new FileOutputStream(fichero);

    Se crea la variable fileout de tipo FileOutputStream, asignándole un nuevo objeto que recibe fichero como argumento: este flujo permitirá escribir bytes en el archivo.

  6. 6
    FileInputStream filein = new FileInputStream(fichero);

    Se crea la variable filein de tipo FileInputStream, asignándole un nuevo objeto que recibe fichero como argumento: este flujo permitirá leer bytes del archivo.

  7. 7
    int i;

    Se declara una variable entera llamada i, que se reutilizará más abajo como contador y como valor leído.

Página 17: EscribirFichData

Aquí en vez de FileOutputStream a secas (que solo escribe bytes sueltos), se envuelve ese flujo con un DataOutputStream, que añade métodos como writeUTF() y writeInt() para escribir directamente tipos de datos primitivos (cadenas, enteros...) en el fichero binario FichData.dat.

EscribirFichData.java 
import java.io.*;

public class EscribirFichData {

    public static void main(String[] args) throws IOException {

        File fichero = new File("FichData.dat");
        FileOutputStream fileout = new FileOutputStream(fichero);
        DataOutputStream dataOS = new DataOutputStream(fileout);

        String nombres[] =
                    {"Ana","Luis Miguel","Alicia","Pedro","Manuel",
                     "Andrés", "Julio","Antonio","María Jesús"};

        int edades[] = {14,15,13,15,16,12,16,14,13};

        for (int i=0; i<edades.length; i++){
            dataOS.writeUTF(nombres[i]);
            dataOS.writeInt(edades[i]);
        }
        dataOS.close();
    }
}

Página 18: LeerFichData

Este programa lee de vuelta el fichero FichData.dat generado en la Página 17, usando DataInputStream para recuperar los datos con readUTF() y readInt(), respetando el mismo orden en el que se escribieron: primero el nombre y luego la edad.

LeerFichData.java 
import java.io.*;

public class LeerFichData {

    public static void main(String[] args) throws IOException {
        File fichero = new File("FichData.dat");
        FileInputStream filein = new FileInputStream(fichero);
        DataInputStream dataIS = new DataInputStream(filein);
        String n;
        int e;

        try {
         while (true) {
             n = dataIS.readUTF();
             e = dataIS.readInt();
             System.out.println("Nombre: " + n + ", edad: " + e);
         }
         }catch (EOFException eo) {}

        dataIS.close();
    }
}
